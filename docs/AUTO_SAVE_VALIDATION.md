# Chrome 本地自动保存验收（2026-09-15）

## 实现

- 使用已有本地克隆，远端地址为 `https://github.com/GeorgeGuo1215/surgery_ComputerVison_Analysis.git`。
- 默认每 300 秒保存当前全部心率记录为 CSV，保存频率与采样频率分开。
- 暂停 / 离线分析结束后补存；无数据或内容未变化时不重复导出。
- 提供 Chrome 文件夹授权后直接写入，以及默认下载两种方式；默认下载只标记请求发出，不冒充写入成功。
- CSV 新增记录 ID、UTC 时间、Unix 毫秒时间戳、采集及分析时间；未输入视频起始时间时不生成虚构的绝对对齐时间。
- 实时画面的采集时间记录在截帧时，避免计入 OCR 耗时。

22 个测试文件、170 项测试全部通过；TypeScript、PWA 静态资源检查和 Vite 生产构建通过。
